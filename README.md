# 🚀 Neon Drift

A polished, responsive, browser-based arcade survival game built with **vanilla HTML, CSS, and JavaScript**. No frameworks, build tools, or installation needed.

## 🎮 Play
Open `index.html` in any modern browser. Or try the live GitHub Pages demo after deploying.

- **Move:** WASD or arrow keys
- **Mobile:** touch and drag
- **Pause/resume:** P, Escape, or the Pause button
- **Goal:** dodge pink asteroids, collect cyan energy orbs (+100 points), and grab green shields (8 seconds of protection).
- Difficulty increases every 18 seconds. You have 3 lives.
- High scores are saved locally in your browser.

## ✨ Features
- Responsive canvas gameplay, including mobile touch controls
- Increasing difficulty and procedural obstacles
- Particle effects, neon glow, and screen shake
- Web Audio sound effects with mute toggle
- Shield power-ups and collectible score bonuses
- Pause/resume, restart, and saved high score
- No external JS dependencies

## 🛠️ Tech stack
HTML5 Canvas · CSS3 · JavaScript ES6 · Web Audio API · Local Storage

## 🚀 Publish to GitHub Pages
1. Create a new public GitHub repository named `neon-drift`.
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the root of the repository.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait for deployment. Your game will be available at `https://YOUR_USERNAME.github.io/neon-drift/`.
